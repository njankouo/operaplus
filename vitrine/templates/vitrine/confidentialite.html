Politique de confidentialité

Nous collectons le minimum de données, uniquement pour répondre à vos demandes.

Données collectées par le formulaire de contact

  • Nom, adresse e-mail, organisation et message ;
  • le nombre de projets et d'utilisateurs, si vous utilisez le simulateur ;
  • une empreinte non réversible de votre adresse IP, pour limiter les envois abusifs (l'adresse IP elle-même n'est pas conservée).

Pourquoi

Uniquement pour vous répondre et, si vous le demandez, vous proposer une démonstration ou une offre. Vos données ne sont ni vendues ni cédées.

{{ entreprise.conservation|default:"Le temps nécessaire au traitement de votre demande, puis elles sont supprimées." }}

Cookies et stockage

  • csrftoken : cookie technique qui protège les formulaires contre les envois frauduleux ;
  • sessionid : cookie de connexion, uniquement si vous vous connectez à votre espace ;
  • vos préférences d'affichage (fermeture du bandeau d'information), enregistrées dans votre navigateur.

Ce site n'utilise aucun cookie publicitaire ni de mesure d'audience.
